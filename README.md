# 🏥 Doctor Appointment Booking System

## 📖 Project Overview
The Doctor Appointment Booking System is a full-stack web application that allows patients to view doctors, book appointments, and contact the hospital. Appointment details are submitted through a web form and stored using a Node.js and Express.js backend.

---

## ✨ Features

- Home Page
- Doctors Page
- Appointment Booking
- Contact Page
- Responsive User Interface
- Backend API using Express.js
- Appointment Data Storage

---

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Storage
- JSON File (appointments.json)

